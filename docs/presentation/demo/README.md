# Demo: the full-trust depot opening, live and recorded

How to run the full-trust journey with the customer's view in a browser, what the recorded video shows, and how to
record it again. The offline command-line demos are described in the
[technical reference](../../TECHNICAL_REFERENCE.md#3-offline-demos).

**What the demo shows.** An independent personal agent, running as its own process, coordinates a synthetic depot
opening:
- the customer acts on the bank's own pages;
- the bank's deterministic policy decides;
- only the depot provider's signed callback opens the account;
- every step lands in the audit trail.

The negative cases then show what is refused.

**What is real and what is not:**
- **Real local implementation:**
  - the FastAPI routes, database persistence and state transitions;
  - the OIDC protocol handling, delegation, DPoP and the policy gates;
  - hash and signature verification, the audit records, and the source verification of claims.
- **Synthetic or mock:**
  - the customers (`alice-synthetic`, `bob-synthetic`) and the trust authority;
  - identity proofing, KYC and AML, the test signer and the depot provider;
  - the product catalog, the partner banks and the policy rule sets.
- **Not implemented as live regulated services:**
  - eID or VideoIdent, and real bank onboarding;
  - a QTSP or QES, and a production custodian;
  - a certified trust federation.

No language model is called in this demo; the agent process is deterministic.

## Setup, once

1. Python 3.12 and the project: see [Getting started](../../../README.md#getting-started). The `.[dev]` extra installs
   the local OIDC provider (Authlib, Flask).
2. For the browser part: Node.js 18 or later. The browser driver is the project's own pinned dependency,
   `playwright` 1.64.1, in `scripts\demo_recording\package.json` with its `package-lock.json`. Install it once, from the
   repository root:

   ```powershell
   cd scripts\demo_recording
   npm ci
   npx playwright install chromium
   cd ..\..
   ```

   The demo uses the installed Google Chrome when it exists, and otherwise Playwright's own Chromium
   (`$env:BROWSER = "chromium"` forces it). `node_modules` is git-ignored.
3. No API key, no network beyond `127.0.0.1`, no paid service. The services pick free ports on `127.0.0.1` at start;
   nothing has to be configured.

## Run it

**The customer's view in a visible browser** (about 65 seconds), from the repository root:

```powershell
$env:RECORD = "0"; $env:HEADLESS = "0"; $env:TERMINAL_DEMO = "0"; $env:PACE = "0.8"
node scripts\demo_recording\record_fallback.cjs
```

The script starts four local services (the bank, the trust authority, the OIDC provider and the synthetic providers)
and the agent process, then plays the customer in the browser. It ends with `ALL CHECKS PASSED`.

**The whole journey plus the negative cases** (about 20 seconds):

```powershell
.\.venv\Scripts\python.exe -m scripts.demo_trust_journey
```

It ends with `RESULT: PASS`.

| Checkpoint | What happens |
|---|---|
| **A. Agent and provider trust** | The agent process checks the bank's signed metadata against a trust anchor. The licence stays `NOT_ESTABLISHED` because the authority is synthetic |
| **B. Customer control** | The customer signs in at the separate identity provider with OIDC and PKCE, never through the agent, then allows exactly the listed scopes for this product. The page states what the agent cannot do |
| **C. The customer's steps** | Identity proofing, tax information and the knowledge questions; **Confirm** appears only when all three exist. The customer confirms the exact action and authorizes the package hash at a test signer with no legal effect |
| **D. The bank decides** | The agent submits; the bank's gates check everything. Only the provider's signed callback opens the depot |
| **E. Audit and refusals** | The ordered audit trail; a forged authority and a revoked delegation are refused; a failed identification goes to a person, who rejects it on the trusted console, and even then nothing opens |

## Recovery

| Problem | Do |
|---|---|
| The browser does not open | Set `$env:HEADLESS = "1"` and rerun |
| A service does not start in time | Rerun: ports are chosen afresh each time |
| `ModuleNotFoundError` for authlib or flask | Reinstall with `pip install -e ".[dev]"` |
| `no playwright under ...` | Run `npm ci` in `scripts\demo_recording` |
| `Executable doesn't exist` for Chromium | Run `npx playwright install chromium` in `scripts\demo_recording` |
| Leftover processes after an interruption | Close the terminals; temporary data is in `%TEMP%\trusteq_trust_*` and can be deleted |

Every run uses a fresh temporary database and removes it at the end.

## Recording the video again

```powershell
cd scripts\demo_recording; npx playwright install ffmpeg; cd ..\..
Remove-Item Env:RECORD, Env:HEADLESS, Env:TERMINAL_DEMO -ErrorAction SilentlyContinue
$env:PACE = "1.3"
node scripts\demo_recording\record_fallback.cjs
$out = "docs\presentation\demo"
ffmpeg -y -i "$out\TRUSTEQ_Demo_Recording_Source.webm" -c:v libx264 -crf 22 -pix_fmt yuv420p `
       -movflags +faststart -an "$out\TRUSTEQ_FullTrust_Demo_Fallback.mp4"
```

The first command downloads Playwright's own ffmpeg, about 1.6 MB, which its video capture needs. The conversion needs
a full ffmpeg. The raw WebM recording is an intermediate file and is not kept in the repository.
